========================================
1. INTRODUCTION
========================================

Dynamic Chess Analyzer is an AI-assisted computer vision project designed to analyze real-world chess games using a webcam. The system captures the chessboard through a camera, processes the image, detects the board structure, identifies movement of pieces, and communicates with the Stockfish chess engine to analyze the game.

The project demonstrates the practical implementation of:
- Computer Vision
- Image Processing
- Artificial Intelligence
- Chess Engine Integration
- Real-Time Move Analysis

The primary goal of the project is to create a low-cost intelligent chess analysis system capable of detecting moves from a physical chessboard and providing strategic suggestions in real time.

5. CAMERA INPUT MODULE
========================================

Purpose:
Capture real-time chessboard image using webcam.

Implementation:
- OpenCV VideoCapture() is used.
- Frames are continuously read from webcam.

Concepts Used:
- Frame acquisition
- Real-time image processing

Explanation:
The camera acts as the input device for the system. Every frame captured by the camera becomes the source for further image processing.

========================================
6. IMAGE PREPROCESSING MODULE
========================================

Purpose:
Improve image quality for board detection.

Techniques Used:
1. Grayscale Conversion
2. Gaussian Blur
3. Canny Edge Detection

Explanation:
- Grayscale reduces image complexity.
- Gaussian Blur removes noise.
- Canny Edge Detection highlights boundaries.

Advantages:
- Faster processing
- Better contour detection
- Improved board localization

========================================
7. CHESSBOARD DETECTION MODULE
========================================

Purpose:
Detect the outer boundary of the chessboard.

Techniques Used:
- Contour Detection
- Polygon Approximation

Process:
1. Detect contours from edge image.
2. Find largest quadrilateral contour.
3. Assume it is the chessboard.

Important Functions:
- cv2.findContours()
- cv2.approxPolyDP()

Explanation:
The system identifies rectangular boundaries in the image and selects the largest four-sided contour as the chessboard.

========================================
8. PERSPECTIVE WARP MODULE
========================================

Purpose:
Convert angled board view into top-down view.

Concept Used:
Perspective Transformation

Functions Used:
- cv2.getPerspectiveTransform()
- cv2.warpPerspective()

Explanation:
The chessboard may appear tilted due to camera angle. Perspective transformation mathematically converts it into a flat 2D representation.

Manual Corner Selection:
Manual selection of 4 corners is used for stable and accurate warping.

Advantages:
- Better accuracy
- Stable detection
- Reduced contour errors

========================================
9. GRID SEGMENTATION MODULE
========================================

Purpose:
Divide board into 64 squares.

Method:
- Board resized to 800×800.
- Each square becomes 100×100 pixels.

Output:
- board_map dictionary
- individual square images

Chess Coordinate Mapping:
- a8 to h1

Explanation:
This module converts the warped board into smaller analyzable square regions.

========================================
10. PIECE DETECTION MODULE
========================================

Purpose:
Detect whether a square contains a piece.

Technique Used:
- Thresholding
- Pixel Density Analysis

Working:
1. Convert square to grayscale.
2. Apply threshold.
3. Count foreground pixels.
4. Classify as:
   - piece
   - empty

Current Limitation:
The system currently detects only piece presence, not exact piece type.

========================================
11. BOARD STATE REPRESENTATION
========================================

Purpose:
Create digital representation of chessboard.

Output Example:

[
['piece','piece',...],
['empty','empty',...]
]

Explanation:
The board state matrix stores occupancy information of all 64 squares.

Importance:
Required for:
- move detection
- board comparison
- AI analysis

========================================
12. MOVE DETECTION MODULE
========================================

Purpose:
Detect player move between frames.

Technique:
Frame-to-frame board comparison.

Working:
1. Save previous board state.
2. Compare with current board state.
3. Detect changed squares.
4. Generate move notation.

Example:
e2 → e4

Explanation:
Movement is detected by identifying differences between consecutive board states.

23. VIVA QUESTIONS AND ANSWERS
========================================

Q1. Why use OpenCV?
Answer:
OpenCV is used for image processing, contour detection, warping, and visualization.

Q2. What is Perspective Transformation?
Answer:
It converts a tilted image into a top-down flat view.

Q3. Why use Gaussian Blur?
Answer:
To reduce noise before edge detection.

Q4. What is Canny Edge Detection?
Answer:
An edge detection algorithm used to identify object boundaries.

Q5. Why is FEN needed?
Answer:
Stockfish requires chess positions in FEN notation.

Q6. What is Stockfish?
Answer:
An open-source AI chess engine used for game analysis.

Q7. What is contour detection?
Answer:
Technique used to detect object boundaries in images.

Q8. Why use manual corner selection?
Answer:
To improve stability and avoid incorrect warping.

Q9. What is move detection?
Answer:
Comparing previous and current board states to identify movement.

Q10. Future improvement?
Answer:
Automatic piece classification using deep learning.
